# Cubicador 3D Pro

Aplicación web interactiva desarrollada para la arquitectura y la construcción orientada al cálculo automático de materiales planos, estimación de superficies perimetrales y presupuestos en tiempo real.

## Características
- Cálculo paramétrico en tiempo real: Modifica las dimensiones del recinto y obtén resultados instantáneos.
- Gestión de desperdicios: Factor de merma ajustable por proyecto.
- Exportación: Generación de reportes limpios listos para exportar a CSV o imprimir.
