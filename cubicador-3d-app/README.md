# Cubicador 3D para la Industria de la Construcción y Arquitectura

Aplicación web interactiva para la estimación rápida de materiales planos (planchas, cerámicos, revestimientos, tabiquería), generación de layouts y cálculo de costos totales de proyectos en el sector de la construcción.

## 🚀 Características Principales
- **Cálculo Automático de Materiales:** Estimación precisa basada en dimensiones de superficie (m²) y desperdicio configurable.
- **Visualizador Dinámico:** Interfaz moderna y responsiva orientada a profesionales de la arquitectura e ingeniería.
- **Exportación y Presupuesto:** Cálculo de costos totales detallados listos para presentar.

## 🛠️ Tecnologías Utilizadas
- HTML5 / CSS3 (Tailwind CSS)
- JavaScript (ES6+)
- Preparado para despliegue en GitHub Pages, Vercel o Netlify.
